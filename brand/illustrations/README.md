# Illustrations

## Preferred

- Real people doing real work
- Clean vector illustration, flat, using the brand palette
- Modern photography, naturally lit

## Avoid

**Anything that immediately looks AI-generated.** The tell-tales:

- Plastic, over-lit surfaces
- Hands and text that fall apart under inspection
- Glowing blue circuitry, neural-network motifs, floating holograms
- Robot mascots
- Humanoid figures with unnaturally symmetrical faces

Also avoid: generic corporate stock (handshakes, boardrooms), isometric tech
clichés, and anything with a dark or neon palette.

## The rule

**If we cannot source something real, use nothing.**

Whitespace is always better than a stock image of a robot. An empty state with
one clear sentence and one button is more premium than the same state decorated
with an illustration that undermines the brand.

This directory is empty on purpose. It stays empty until there is real artwork
of real work to put in it.

## If commissioning

- Flat vector, no gradients except the brand rule
- Two accent colours maximum, from `../colors/palette.md`
- Line weight matching Lucide at `1.5`
- Generous whitespace inside the artwork itself
- Must read correctly at 320px wide
