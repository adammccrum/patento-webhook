## Key Architectural Components to Develop

### 1. Dual-Brain Architecture
- **Reasoning Brain:** Model-agnostic LLM reasoning
- **Authority Brain:** Deterministic authorization, independent verification

### 2. Five-Gate Authority Engine
1. **Identity Gate:** Verify agent identity & credentials
2. **Policy Gate:** Evaluate against active authorization policies
3. **Action Gate:** Validate requested action against role/scope
4. **Context Gate:** Analyze request context for anomalies
5. **Execution Gate:** Monitor execution and enforce revocation

### 3. Verified Memory Architecture
- Tamper-evident knowledge graphs
- Integrity-verified embeddings
- Audit trail for all memory modifications

### 4. Authority Tokens
- Cryptographic token lifecycle
- Dynamic authority delegation
- Deterministic revocation triggers

### 5. Multi-Agent Trust Fabric
- Cross-agent authentication
- Delegation protocols
- Conflict resolution in multi-agent systems

## Threat Model Coverage

### Critical Threats to Address
1. **Prompt Injection** – Crafted inputs manipulating agent behavior
2. **Memory Poisoning** – Corrupting learned behaviors/knowledge
3. **Tool Misuse** – Unauthorized use of external tools
4. **Credential Theft** – Stealing authentication credentials
5. **Cross-Agent Attacks** – One agent compromising another
6. **Agent Impersonation** – Masquerading as legitimate agent
7. **Privilege Escalation** – Autonomous expansion of authority
8. **Supply-Chain Compromise** – Tampered models or dependencies
9. **Insider Misuse** – Authorized user abuse
10. **Context Manipulation** – Exploiting reasoning via false context
11. **Rogue Autonomous Agents** – Deliberately malicious agents

For each threat: description → current mitigation → IrisKey solution

## Writing Standards

### Style Guidelines
- British English (e.g., "organisation" not "organization")
- Active voice where possible
- Define acronyms on first use
- Technical precision over marketing language
- Formal academic tone

### Structure Per Section
1. Introduction paragraph (context & relevance)
2. Sub-section development
3. Connection to Five-Gate Authority Engine
4. Real-world application example
5. Summary/transition

### No Marketing Language
❌ "Revolutionary" "groundbreaking" "unprecedented"  
✅ "Proposed architecture" "extends" "addresses" "provides deterministic"
